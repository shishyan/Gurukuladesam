# Veena reference checkpoint

Primary museum reference: https://www.metmuseum.org/art/collection/search/505637

The Met identifies this as a Tanjore-style Sarasvati vina. Its description places the yali head and secondary gourd-shaped bowl at the upper end, and describes metal frets mounted on wax along neck-side rails. Use these relationships to reject the earlier reversed/malformed instrument layouts.

This is a ca. 1935 specimen: use as structural reference, not evidence of exact early-Chola-period construction. The page restricts image downloading; do not assume its photograph is available for production reuse. A visual reference still needs inspection before a replacement instrument render is approved.

Keep instrument and incense in separate shots. Use woven cloth, not raw cotton. No smoke emerging from the instrument or a lamp.
